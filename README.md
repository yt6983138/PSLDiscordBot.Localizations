Localization for PSLDiscordBot

## Translations
Translations are managed with [Weblate](https://weblate.org/) in the [PSLDiscordBot project](https://hosted.weblate.org/projects/psldiscordbot/). Make translations in Weblate rather than through direct pull requests to the translated files, since Weblate commits to this repository. Want to help? Join via the [Weblate engage page](https://hosted.weblate.org/engage/psldiscordbot/). Thanks to Weblate for providing free libre hosting!
